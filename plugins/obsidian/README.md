## 新插件目录额度

后台上线后，每个账号默认可开通 5 个“学段 × 学科”范围。例如初中数学占 1 个，同范围不同教材、知识点和重复下载共用额度；和每天的题目额度分开。首次下载新范围会占 1 个，管理员可调整总额度，同账号的多个 Key 共用。空目录、数据库失败不占额。

插件通过 capabilities 自动识别服务版本；明确收到 404（后台未发布）时维持原目录访问，后台发布后使用自己的 Key 访问受限接口。权限错误、额度不足或网络失败不会退回公开接口。缓存不能替另一个账号开通范围。

按本次产品决定，旧公开元数据接口继续保留，旧 skill 文件不变。该版本控制新插件下载范围，不代表网站全部目录已经防采集。已有本地知识树属于老师的离线文件，仍可用于分类。

## 组卷与资料库功能

网站取题和本地题库沿用官网“题庄”文字叠加造型，使用当前主题文字色和透明背景；整体继续使用 Obsidian 主题与现有紫色按钮。字标内置于插件，离线也可显示。

## 可选章节和知识点筛选

“网站取题”中，学科和学段必选；教材版本、年级／学期、章节、知识点为可选项。章节与知识点并列显示，二选一，也可都不选。选章节自动清空知识点，选知识点自动清空章节；选择章节需要对应教材版本。选择和留空状态均会记住，切换学期仍在本地即时筛选目录。

两个节点都不选时，覆盖当前学科学段的知识树范围，并叠加用户选择的教材、年级条件。现有网站接口没有独立学段参数，插件使用该学段所有知识树根节点的一次联合查询；只覆盖已关联该知识树的题目，不冒充整个网站全部题目，也不拆成多次收费请求。选择确定的章节或知识点时直接使用所选节点。

顶部“章节目录／知识点目录”可打开已有本地导航；已选择时显示“定位章节／定位知识点”。按笔记属性中的编号寻找，即使文件改名也可定位，展开左侧文件列表并保留当前筛选。直接点击范围标题也能打开节点。节点尚未下载时回到已有目录并提示，不生成空白笔记。Obsidian 若未提供文件列表定位接口，仍会打开节点正文。点击目录不会取题或扣额度。

新取题缓存使用 tizhuang.pending/v2，兼容恢复旧 v1 缓存；保存同时保留教材和知识树两套关联，继续与独立本地 skill 互通。此次不更改网站后端或旧 skill。

## 可视化组卷篮

在“我的题目”勾选加入组卷篮，跨教材、知识点、标签筛选仍保留选择。打开 **组卷篮**，拖动左侧把手或点击上下移调整题序，修改每题分值、标题、考试时长和作答留白。总分即时汇总，题库原题的默认分值保持不变；关闭面板或重启后恢复。

点击 **生成试卷与教师答案**，得到分别可打开的无答案试卷和教师答案版，两版独立保存本地图，可在浏览器打印 / 保存为 PDF。若含待核对题，需要老师查看原题和答案并主动勾选已逐题核对；生成前验证图片，原答案缺失会如实标注。失败保留组卷篮，重试同一请求复用已完成输出。修改题序/分值/设置或点击“开始新一版”会创建新的试卷快照。

沿用题庄网站的学科学段建议时长、每题 0—1000 分与题序规则，并适配网站纸张布局。网站加题接口需要账号及云端题号且会扣额，所以本地篮使用新 skill 的独立生成引擎，已有网站题和 PDF 题均可用，不调用收费加题接口。最多 200 题；本版同时输出无答案与教师答案两份 DOCX，以及 HTML 打印文件；PDF 由浏览器打印保存。尚未实现云端同步。

## 教师工作台

左侧书库图标现在打开 **首页**：查看全部题目、待核对、待分类、最近保存、PDF 导入进度和已有试卷。**我的题目**支持教材章节树、标准知识点树和原生标签树；可以同时按题干、检索文字、题型、审核状态筛选。点击分类先浏览本地题，需要时再从网站补题。分类、标签及筛选选择会保存。

PDF 的 Agent 导入指令会要求关联本地真实知识节点，综合题可多选。已有题可由新 skill 批量补知识点分类；首页按当前分类展示，不再受旧“待分类”文件夹位置影响。老师手动调整分类时，同步更新自动生成的知识点链接。未确定教材时不推断章节。

列表以清洁的题目名称显示，带图题目左侧标 `[图]`，展开后看完整原题及答案解析。点击 **分类 / 标签** 可多选知识点和修改层级标签；先备份笔记，保留老师批注。中文 `标签` 兼容旧笔记，新文件用 Obsidian 原生 `tags`；两者同时存在时以 `tags` 为准。

教师目录使用 `题库首页.md、题目库、待整理、试卷、教学笔记、资料`。题目只保存一份，按学科学段和主分类存放，通过索引支持多个考点和标签。素材放在 `资料/附件`，原件放在 `资料/原件`；平时从题目和导入报告打开。已有中文仓库由独立本地 skill 的 `organize` 命令备份后迁移，空白 Bases 视图归档，自定义文件保留。

## PDF 导入

**导入 PDF → 选择试卷 → 确认范围 → 准备导入 → 复制 Agent 指令**。插件保存原页和候选文字，由 Agent 逐页核对，生成可编辑题干、选项、LaTeX 公式、表格和独立配图。去掉正文原题号和图片中的“第几题图”，原编号只留在来源，保留小问与多图对应。不会再把单栏题自动存成整题截图。所有导入题先为待核对；原答案缺失保持空，识别疑点明确列出。旧图片草稿可使用新 skill 的 `--upgrade-to-editable` 备份升级，老师已编辑内容不会被覆盖。

PDF 和目录整理需要 Python 3.10+ 及 `helper/requirements.txt` 中的依赖。插件设置可指定 Python 程序路径，留空使用系统 `python`；普通本地浏览和网站取题不需要 Python。插件随包携带独立 helper，不读取另一个 skill 的代码。单份 PDF 最多 100 MB、120 页，每次处理等待最多 120 秒；重复导入复用文件批次，不增加重复题。PDF 工具不调用远程模型、不扣网站题目额度；扫描识别由所用 Agent 完成。

本地组卷可用插件或 `tizhuang-local-bank`，共用组卷篮协议和同一生成引擎。Agent 可通过 `paper --basket <JSON>` 接着整理；Agent 和插件均默认生成双版 DOCX。

独立插件，全中文菜单。按学科、学段、教材版本、年级/学期、章节取题，预览、选择保存。使用用户自己的题庄 API Key 和今日题目额度；没有游客回退，不读取已有 skill 的凭证。

## 更简单的入口

在左侧打开已下载的教材章节或标准知识点，已打开的题库面板会同步范围。也可右键节点选择 **从此章节获取题目 / 从此知识点获取题目**，或在节点阅读模式点击同名按钮。设置范围不扣题目额度；后台目录额度上线后，首次下载新的学段和学科会占用 1 个目录范围，点击获取并确认后才查询题目。

原筛选面板保留在 **筛选取题范围** 中。自动记住学科、学段、教材、年级/学期、章节或知识点、题数、答案解析开关、面板展开状态；重启仍回到同一个界面。清除凭证不会清除这些偏好。知识点取题含子节点。从左侧知识树带入范围时清空此前教材条件；在筛选面板中可明确添加教材、年级条件，不推断未确认的教材关联。

独立本地 skill 生成的节点已带所需中文属性。自建树笔记只有节点名称时无法可靠确定网站 ID；须保留 `学科编号`、`学段编号`，以及教材节点的 `教材版本编号`、`章节编号`，或知识点的 `知识节点编号`。普通笔记不会自动变成取题范围。

按顺序分页取题，成功后记住当前范围下一页的位置；失败不前移，不自动重试、不放宽条件。遇到 HTTP 500/504 等错误显示原因并免费刷新额度，展示请求前后今日已用额度。

## 加载与按钮

加载目录期间仍可切换学科、教材和学期，旧请求的迟到响应不会覆盖新选择。完整版本目录加载一次，切换学期只做本地筛选。公开目录在内存与本地缓存 24 小时，重启可复用；会优先使用 24 小时内已有的共享目录快照。

目录与额度请求 10 秒超时，付费取题等待 35 秒，图片下载 20 秒。超时会提示并恢复操作；付费请求不会自动重试，扣额状态需刷新确认。额度和付费题目不使用目录缓存。

取题范围、题数、答案开关和额度集中在操作卡片中。「获取题目」「保存到本地」为主按钮，保存按钮实时显示所选未保存题数。右上角地球图标打开题庄官网；凭证设置移到额度旁的钥匙图标。刷新额度和清空结果使用带中文提示的图标；「重新加载目录」放在 **筛选取题范围 → 更多目录操作** 中，只在目录更新或异常时使用，绕过本地缓存请求网站。网站目录缓存如启用，最多保留 1 小时。

题目卡片显示勾选框、网站提供的题型、中文难度、考点和「未保存 / 已保存」状态，不再放大显示网站题号，也不显示「选择此题」。题型使用暖色标签，难度使用淡紫色标签；考点过长时省略，悬停可看完整内容。顶部支持全选；已保存题目不可重复勾选，可直接打开本地笔记。题型缺失时显示「未分类」，不根据内容猜测；未标注的难度不强行显示。

难度分组参考网站筛选区间：0—2 显示「简单」，大于 2 且小于 4 显示「中等」，4—5 显示「困难」。只改变界面标签，原始数值及本地题库格式保持不变。

点击卡片右上角 **详情**，展开答案和解析。解析下方以紧凑的一行显示「年份 · 地区 · 原试卷来源 · 来源题号」，较长时自然换行；不再显示顶部属性表。详情默认收起；在当前面板中保存后仍保持展开状态。展示使用本次已获取内容，不再请求题目、不再扣题目额度，公式图片按需加载。未勾选「含答案解析」时明确提示本次未包含；网站没有提供答案或解析时也明确提示。

来源信息仅在网站有值时显示。不将取题范围、内部试卷类别编号、默认分值或推测的年级当作来源信息展示。

面板随 Obsidian 深浅主题切换；题目始终使用白底与深色文字，公式和配图保持原色，不做反色。压缩卡片间距和段落空白，窄面板自动调整筛选布局。此白底展示用于插件预览；保存的 Markdown 笔记继续使用 Obsidian 阅读主题。

## 安装测试

1. 解压发行包，把 `tizhuang-question-bank` 文件夹放到 Obsidian 仓库的 `.obsidian/plugins/` 下。
2. Obsidian → 设置 → 第三方插件，关闭受限模式，刷新插件列表，启用 **题庄本地题库**。
3. 插件设置中填写自己的题庄 API Key。新版本可选保存到 Obsidian 密钥存储；旧版本仅本次运行使用。不要把凭证发到聊天中。
4. 点击左侧书库图标进入首页；在“网站取题”选择学科、学段、教材版本和章节，刷新额度。
5. 输入题数，点击 **获取题目**，确认扣额。勾选题目，再点击 **保存到本地**。

升级后在第三方插件中关闭再启用一次，或重启 Obsidian。已有题目、密钥引用、个人笔记保留。

此发行版尚未提交 Obsidian 社区插件市场。推荐用完整起步包让 Agent 自动安装；首次启用第三方插件仍需老师本人确认。本版面向电脑端老师。

## 额度与恢复

教材元数据和额度查询不扣题目额度。网站按实际返回题数计入用户今日额度，并非充值钱包金额；以网站返回为准。重复取题仍会扣额，本地去重不退额。

保存失败可重试保存，已成功的题目不覆盖。不自动重试收费请求。收费请求网络结果不确定时先刷新额度。已收到的结果暂存 `.bank/pending/questions.json`，重新打开面板自动恢复，不重复扣额；缓存写入失败会明确提示保持面板打开并立即保存。第一版不要同时用 Agent 和插件写入同一仓库。

## 共用本地题库格式

- `题目库/*.md`：题目正文和中文属性，`tizhuang.question/v1`，题目/答案/解析三段标记。
- `附件/<sha256>.<扩展名>`：题目图片，正文使用相对路径。
- `.bank/records/<题目编号>.json`：原始网站响应及附件登记；未勾选答案解析时原始副本也移除这两项。
- `.bank/textbooks/<学科>-<学段>-<教材版本>.json`：完整版本章节快照。
- `.bank/config.json`：`tizhuang.bank/v1`。
- `网站取题导航.md`：插件导航，不覆盖已有 skill 的导航。

兼容独立 `tizhuang-local-bank` skill 的检索、按版本/章节选题、组卷、导出。网站取题直接调用网站接口；PDF 使用插件自己的本地 Python helper。现有 `question-bank` skill 保持独立，未来视频 skill 读取同一题目协议即可。

题目默认「待核对」，答案不作自动正确性保证。章节关联来自本次实际取题筛选条件，不通过知识点名称猜测教材。图片本地保存失败时不会生成缺图题目。网站原始响应留作核对，转换为 Markdown 的正文可在 Obsidian 编辑，保留编号和区块标记。复杂表格/MathML 保留 HTML 结构。

API Key 只发给固定题庄服务的受限目录、额度和取题接口，不发给图片服务或其他域名，不写入题目、日志、发行包。插件配置只保存密钥引用。不要将包含 Obsidian 密钥存储的个人应用数据整体分享。

## 开发验证

`npm ci` → `npm test` → `npm run build`。发行目录 `dist/tizhuang-question-bank/`。跨语言兼容测试还需独立本地 skill 的 Python 环境。

接口基于当前 `/api/v1/meta/*`、`/api/v1/quota`、`/api/v1/questions`；未配置个人凭证前不会发起真实收费取题请求。


## Word 与 Agent 组卷

生成后点击“编辑无答案 Word”或“编辑教师答案 Word”，用系统默认的 Word/WPS 打开。文字、普通表格和支持的 TeX 公式为可编辑内容；网站图片、配图及 PDF 原图区域仍是图片，不自动 OCR。全部图片嵌入 DOCX，单个文件即可携带。原题未提供答案时会明确提示。复杂公式或合并表格目前可能报错，需要先整理原题，不静默丢失内容。

Word 编辑后的内容属于该卷，不会自动改回题库或组卷篮。重新组卷请点“开始新一版”，保留老师已编辑的文件。旧版 HTML 试卷仍可打开，重新生成一版即可获得 Word。

给 Agent 的示例：“用题庄本地题库，从指定教材的一次函数章节选 10 道已核对题，按基础到提高排序，总分 100 分，生成无答案 Word 和教师答案 Word。题目不足时先告诉我。”Agent 先检索并检查数量，按实际题目设置题序和分值，然后调用本地 paper 命令；不需要旧 skill，不会重新扣取题额度。
