# 本地题库 2.5.1 / 插件 0.14.1

这次更新解决了“首页显示知识树已下载，但 Obsidian 左侧目录为空”：下载后会生成中文目录笔记，打开首页也会从已有本地快照补齐目录。重复打开不会覆盖老师修改过的笔记，也不重新扣题目额度。

## 老师怎么更新

把 [Agent 安装说明](INSTALL.md) 交给可以操作本地文件的 Agent，并告诉它原题库路径。安装器识别版本、备份程序、更新独立环境并体检；同版跳过，题目、图片、试卷和个人配置保留。更新后重启 Obsidian 或重新启用插件。

完整起步包同时包含空白题库、插件和新 skill，首次使用可看 [图文教程](USER_GUIDE.md)。旧 `question-bank` 无需卸载或更新。

## 本版变化

- 首页“四步用起来”：下载知识树、放入第一批题、核对、组卷，按真实状态显示下一步。
- “我的题目”支持核对本页显示的待核对题；不把屏幕外题目一并确认。
- 设置页可检查环境，区分未安装 Python、超时、脚本异常和缺依赖。
- Agent 的 `doctor`、`status`、`show` 和 `search` 提供清晰状态及处理建议；后三者只读，不重写索引。
- 知识点标签中的括号等标点可正确匹配；有歧义的匹配继续留待判断，不猜教材章节。
- 目录快照与中文树笔记同步，旧快照可离线补齐，保留已有笔记。

PDF 流程测试使用自编样卷；测试里的核对确认只针对这些样卷，不替老师确认真实题目。PDF 识别仍由能看原页的 Agent 完成，插件本身不会在后台调用模型。

离线组件检查不能替代原生 Obsidian。测试期间电脑锁屏，0.14.1 更新后的原生重载、最后点击验收，以及在 Word / WPS 中实际打开导出文件，仍需解锁后完成。这里不将它们计为已通过。

## 校验与边界

完整包 SHA256：`c1e81ef74b191c39c65011d8eeb695e79d159ecc0ea91daa38ecf805f351ae36`。

包内没有账号密钥、预装题目、个人试卷或 Python 运行时；安装器会按本机环境创建所需的独立 Python 环境并安装依赖。首次安装可能需要网络，Obsidian 的首次信任提示仍由本人确认。

本版不修改旧 skill、旧公开目录接口或网站后台额度规则。不承诺任意 PDF 均可自动准确识别；识别疑点与原文答案仍需教师核对。
