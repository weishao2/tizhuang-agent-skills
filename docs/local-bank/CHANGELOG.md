# 更新记录

## V2.5.0

- 新增只读体检 `doctor.py`（仅标准库，环境缺失时也能运行）与 `status`：题量、待核对、待分类、知识树及下一步建议。
- 新增 `show --ids`：读取题干、答案、解析及 `classify` 所需的 `content_sha256`，补上此前无法从 CLI 取得内容哈希的缺口。
- `search --limit`；所有失败返回 `hint`（下一步怎么修）；缺依赖或未预期异常也返回 JSON，不再输出堆栈。
- SKILL.md 重写为“开场三步 + 任务路由表 + 不可违反规则”，并新增对话指南与知识树/教材参考。
- `doctor.py` 在题库无法读取时返回 `ok:false`/退出码 1；`status`、`show`、`search` 与 `doctor.py` 严格只读（不重写索引与导航笔记），有测试守护。
- 安装后必须运行 `doctor.py` 验收；插件随附 `doctor.py`，设置页新增“检查环境”（自动尝试多个 Python、列出缺项、复制修复命令、一键保存可用路径）。
- `doctor.py` 的修复命令正确引用含空格的路径（Windows 用 PowerShell 的 `& "路径"` 形式）。
- 新增 `requirements-dev.txt`（测试依赖 reportlab）。
