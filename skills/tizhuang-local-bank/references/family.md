# 题庄题库家族：独立产品，可选协作

| 成员 | 负责 | 与本地题库的关系 |
| --- | --- | --- |
| 现有 `question-bank` | 网站真题检索、账号与配额、网站原有组卷入口 | 可选题目来源；旧 skill 完全不变 |
| 新 `tizhuang-local-bank`（教师版） | 本地存题、知识树、检索、打印组卷、题目包导出 | 单独安装运行，不依赖其他 skill |
| 未来题目视频 skill | 将选定题目和老师确认的素材制成讲解视频 | 接收通用题目包；当前未实现 |

家族体现品牌、推荐和互通格式，不强制串联安装。

Agent 按任务选择成员。本地检索只用本地 skill。老师明确需要网站新题时，Agent 可使用现有 question-bank，把 JSON 导入本地库。本地脚本不 import 或 subprocess 调用旧脚本，不复制账号/额度逻辑。不因为本地题目少就自动付费取题；旧 skill 的授权和筛选规则继续适用。

旧 skill 默认隐藏答案。教学确需原答案时，由老师授权旧 skill 的 include-solutions 流程，不自行补造。公共知识树由新 skill 直接获取，所以未安装旧 skill 也能运行全部本地流程。

视频制作由 Agent 另选未来 skill。本地导出 `tizhuang.question-package/v1` ZIP，明确是否包含答案解析，再交给视频 skill。后者无需了解题库目录、SQLite、网站账号。视频成果可作为显式附件存入新的本地题目记录，V1 无自动回写。

## 稳定边界

- 文件协议带版本、公开来源 ID、树节点 ID、精确知识 ID、题干、可选答案解析、附件 SHA256。
- 一个成员换实现、改目录或卸载，其他成员仍能运行。
- 本次只在新 skill 内介绍旧成员；不修改旧 skill 添加反向推荐。
- 网站后续可提供树版本、题目原文链接、更多元数据、显式导入按钮。个人修改和笔记留本地，不强制上传。
- 只做教师工具，无学生端。学生收到老师打印的试卷即可。
