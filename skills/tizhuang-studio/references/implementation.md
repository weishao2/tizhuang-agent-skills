# 实现说明

版本：1.0.1。产品名“题庄 2.0”表示新的使用方式，不覆盖旧在线技能的版本号。

## 结构

- `scripts/studio.py`：本机 HTTP 服务、Agent CLI、环境检查。
- `scripts/engine.py`：取题适配、SQLite 状态、操作幂等与版本冲突、冻结导出快照。
- `scripts/content.py`：安全 HTML / MathML 渲染、附件路径校验。
- `scripts/mcp_import.py`：Agent MCP 结果校验、白名单清洗；OAuth / API Key 接入共用同一保存流程。
- `scripts/word_export.py`：学生版、教师版 Word。
- `scripts/library.py`：目录快照、分类、核对、编辑历史、备份恢复、题目包与独立打印稿。
- `scripts/studio_pdf.py`：原 PDF 和页面保存、文字层辅助、v2 可编辑分题清单校验、独立图形裁图。
- `assets/web/`：独立浏览器界面。
- `assets/demo/`：此前经题庄接口取回的 6 道初中数学题及配图，供明确标注的演示。题干、答案、解析保留原文；知识点短标题取自先前演示素材的标注。
- `tests/`：隔离工作区与假上游接口的回归测试，不消费线上额度。

## 复用与隔离

2026-10-25 从现有 `skills/tizhuang-local-bank` 复制插件 CSS、文字叠加 Logo、安全正文渲染和 Word 转换代码。前端使用原题卡、题型/难度标签、详情与底部来源信息。为独立运行替换了 Obsidian 窗口、文件、弹窗依赖。

旧技能源文件未修改。新技能不在运行时 import 旧目录。后续可在兼容性测试后抽共享组件，这一版先保证隔离。

## 共享篮子与安全

一个工作目录只运行一个服务，文件锁防止双实例。浏览器和 Agent CLI 调用同一服务。SQLite 保存题目、篮子、操作结果；版本号防止过期覆盖；request_id 防止重复操作。浏览器会话限同源及回环地址，拒绝跨站请求和远程 Host，不暴露到局域网。Key 只保存在服务内存，题图下载仅允许题庄和现用题庄图片域名，拒绝跳转，不转发 Key。

生成前冻结题序和分值。两个 Word 均成功后才出现在下载列表。学生版不输出答案/解析，包含子题的答案也不混入题干。Word 中的公式使用 OMML，配图嵌入文档；来源本来是图片公式时仍保留图片。

## 第一版边界

Agent 可使用客户端已连接的题庄 MCP，把 search_questions / get_question 的完整结果经 import-mcp 保存到本工作区。客户端持有凭据；工作台只记录来源类型，不代替客户端登录或续期。重复题号不覆盖已有完整题，隐藏答案可在题干一致时补齐。页面取题仍用 API Key。具体操作见 [MCP 流程](mcp-workflow.md)。

这是“在线取题 + 本机工作台”的预览版本。无需 Obsidian，但 Agent 需能运行本机 Python，界面需能打开本机网页。没有宣称所有 Agent 都支持聊天内嵌；普通浏览器即可使用。

目前单工作区一份活动组卷篮，历史试卷保留。已支持知识点/章节树、标签、题目编辑、核对、PDF Agent 分题、备份恢复和题目包迁移。PDF 识别由能查看原页的 Agent 完成，工作台本身不内置云 OCR 或大模型。自动分类只做唯一同名匹配，语义分类由 Agent 读题完成。

未实现跨设备自动同步、云端私有库、多人协作和公网托管。真实 Key 取题接现有账户及团队额度；两个现有技能、官网、后台、线上服务都不因本预览改变。
