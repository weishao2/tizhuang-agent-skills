# 更新记录

## 1.0.0 · 2026-11-08

题库工作台首个正式版本，作为题庄主推的本地题库技能。旧 Obsidian 版保留历史下载，不自动覆盖其程序和用户题库。

- 我的题目 → 组卷 → 我的试卷，Agent 与界面共用同一题库、组卷篮和修改版本。
- 知识点 / 教材章节树及搜索，学段学科选择、分层标签、批量分类与教师核对。
- PDF 原页准备、Agent 可编辑分题、LaTeX 与独立配图；不猜原答案。
- Word 学生卷与教师答案版、题型分组小计、预览打印、历史稿改名标签与继续编辑。
- 完整备份恢复、v1 题目包迁移、浅深色切换；题目保持白底。
- 标准库安装器：全新安装、独立环境体检、同内容跳过、更新备份并保留题库与未知文件。
- MCP OAuth / API Key 取题结果入库，页面直接取题使用 API Key。

初版边界：数据保存在指定电脑，不自动云同步；PDF 识别需要具备图像能力的 Agent；核对由老师确认。Word 与浏览器打印的分页可能不同。
